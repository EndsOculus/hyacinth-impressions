防止重复填写。每个浏览器限提交一份新答卷。IPv4 按公网地址、IPv6 按 /64 网段各限一份；家人或室友可能共用名额。收票服务用带密钥的摘要去重，问卷数据库不保存明文 IP。提交新答卷时，Cloudflare Turnstile 会接收连接 IP 和浏览器技术信息，不接收题目答案。

网络传输。启用 Cloudflare 代理时，Cloudflare 会收到你的连接 IP，转发答案和浏览器标识。查看、修改或撤回答卷时，它也会转发答卷管理凭证及服务返回的答卷内容。网页托管和网络服务可能保留访问日志。使用 GitHub Pages 时，GitHub 会出于安全目的记录访问 IP。
